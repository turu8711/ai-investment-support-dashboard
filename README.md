# AI Investment Support Dashboard

AIを用いた投資判断支援システムの開発・検証結果を表示する静的サイトです。

## 公開内容

- 本番表示: `view/index.html`
- 銘柄詳細: `view/symbol_detail.html?symbol=2929`
- v2検証画面: `view/test_example.html`
- v1比較画面: `view/test_example_v1.html`
- Web表示用JSON: `test/web/data/`

## 注意事項

- 現在は開発・検証中の結果です。
- 本サイトは投資助言を目的とするものではありません。
- 表示結果は将来の価格変動や利益を保証しません。
- 手数料、税、スリッページ、市場影響などを含まない評価があります。
